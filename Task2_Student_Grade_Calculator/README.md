# Student Grade Calculator (GUI)

This is my second task for CodSoft Internship.

## 💻 Project Description
A Java Swing-based application that calculates total marks, average percentage, and grade of a student.

## 🚀 Features
- GUI-based input
- Input validation
- Grade calculation
- User-friendly interface

## 🛠 Technologies Used
- Java
- Swing (GUI)

## 📌 How to Run
1. Compile the program:
   javac GradeCalculatorGUI.java

2. Run the program:
   java GradeCalculatorGUI
